A real-time collaborative document editor — a Google Docs clone built to support **hundreds of collaborators editing the same document simultaneously**. Handles presence, multi-cursor editing, comments, and fine-grained permissions via Liveblocks; auth via Clerk; Sentry wired for production observability.
